Private Screen Share

Share one phone's screen to another browser using a temporary pairing code and an encrypted WebRTC connection.

Consent and privacy: Screen sharing starts only after the sender presses Start and approves Android's browser prompt. Stop sharing any time. Do not share banking apps, passwords, or sensitive notifications.

1. Generate a one-time code. Give it only to the person you want to watch.

--------

2. Tap Start sharing and choose the screen or app Android allows you to share.

Keep this page open while sharing. A browser may not support screen capture on every Android device.
Video is streamed peer-to-peer when network conditions allow. A TURN relay may be needed on some networks.
Ready. Choose a role to begin.

Security note: deploy this site on HTTPS. WebSocket signaling should use WSS. The signaling server forwards connection setup only; it does not receive the screen video.
